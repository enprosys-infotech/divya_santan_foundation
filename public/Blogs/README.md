# DSF Blog Markdown Files

This folder contains one Markdown file per supplied Word document.

## Important notes

- The Markdown files preserve the source documents' language, structure and main claims.
- Metadata/frontmatter was added for blog-system integration.
- Editorial notes identify documents or sections that require scientific, medical, historical or philosophical review before publication.
- No article should be presented as a replacement for medical care.
- Review all scientific claims and references before publishing publicly.
