# Womb to World

Build a modern, premium, responsive website demo for Divya Santan Prakalp / Divya Santan Foundation.

1. CORE PURPOSE

This must NOT look like a commercial clinic, hospital, fertility center, or consultation-selling website.

It should feel like a global educational, cultural, scientific and social movement for Garbh Sanskar.

The visitor should immediately understand:

We educate, train, guide, create awareness, conduct research, and work toward healthier, cultured and compassionate future generations.

Consultation is only a secondary supportive service.

Brand Positioning

Divya Santan Foundation

A Global Garbh Sanskar Education, Training & Awareness Platform

Main Tagline

From Womb to World – Nurturing Healthy, Cultured & Compassionate Generations

Hindi Tagline

गर्भ से विश्व तक – स्वस्थ, संस्कारित और करुणामय पीढ़ी का निर्माण

Supporting philosophy:

वसुधैव कुटुम्बकम् – One World, One Family

Use this philosophy subtly throughout the design.

2. VISUAL STYLE

Create a sophisticated Indian heritage + modern scientific + global nonprofit visual language.

Do NOT make it look overly religious, overly traditional, or like a medical website.

Design direction:

Warm, peaceful, spiritual and educational

Premium nonprofit / cultural institution feel

Indian/Sanatan visual influences

Modern typography and spacious layouts

Elegant cards and subtle borders

Soft organic shapes

Subtle mandala / lotus / diya / sun / sacred geometry motifs

Very subtle Sanskrit/Sanatan decorative elements

Avoid excessive religious imagery

Avoid hospital imagery

Avoid stock photos of doctors as the primary visual

Avoid aggressive marketing, pricing, discounts and sales banners

Primary Color

#B65329

Use it as the main brand/accent color.

Supporting palette can use:

warm ivory / cream

off-white

muted beige

deep brown

subtle gold accents

Keep the overall UI light, calm and premium.

3. LOGOS

Use the two provided logo assets in the project.

Do NOT redraw, modify or replace the logos.

Create a tasteful combined branding treatment where appropriate.

Use:

Divya Santan Prakalp logo as the primary identity

Supporting foundation logo in a secondary position

Header should remain clean and not overloaded

Use the supplied transparent logo assets rather than creating fake logo text.

4. MULTI-LANGUAGE SUPPORT

The website must support language switching.

Initial languages:

English | हिन्दी

Create a language switcher in the navbar.

Structure the content so additional Indian/global languages can easily be added later.

For the demo, translate the major navigation labels and homepage hero content into Hindi.

5. NAVIGATION

Keep the navbar concise.

Desktop:

Home | About | Learn | Courses | Knowledge Centre | Free Services | Ask Shree AI | Research | Global Movement | Join Us | Contact

Do not create 16+ top-level navigation items.

Use dropdown/mega-menu behavior for secondary sections.

Primary CTA buttons:

Ask Shree AI

EN | हिन्दी

On mobile, use a clean hamburger menu.
